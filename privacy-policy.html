개인정보처리방침

내 영상 바로가기 개인정보처리방침
시행일: 2026년 10월 21일
적용 대상: Chrome 확장 프로그램 ‘내 영상 바로가기’ 버전 1.0.0

‘내 영상 바로가기’는 사용자가 등록한 영상 주소를 관리하고 실행·재생을 제어하는 기능을 제공합니다. 이 방침은 확장 프로그램이 기기 안에서 어떤 정보를 처리하는지, 그 사용 목적과 저장·삭제 방법을 설명합니다.

1. 사용자가 입력하거나 선택한 정보
영상 슬롯의 이름, 영상 웹 주소, 선택한 아이콘 이미지, 재생 방식, 음량 및 아이콘바 설정을 사용 중인 Chrome 프로필의 확장 프로그램 로컬 저장소(chrome.storage.local)에 보관합니다. 아이콘 이미지는 사용자가 파일 선택 창에서 선택한 PNG·JPG만 읽어 크기를 조정한 뒤 저장하며, 기기의 다른 파일을 탐색하지 않습니다.

2. 기능 작동 중 일시적으로 처리하는 정보
확장 프로그램은 사용자가 허용한 웹페이지의 주소를 기능 적용과 재생 탭 식별에 사용합니다. 확장으로 실행한 영상의 미디어 요소, 재생 시간, 재생·일시정지·종료 상태, 음량 및 지원되는 광고의 표시 상태를 확인하여 재생 제어와 광고 임시 음소거를 수행합니다.
현재 재생 중인 슬롯·영상 주소, 재생 탭 식별정보, 재생 시작 시각 및 제어 상태 등은 Chrome의 세션 저장소(chrome.storage.session)에서 관리합니다. 이는 전체 웹 방문 기록을 축적하기 위한 기록이 아닙니다.
웹페이지의 포인터 위치와 바로가기 바의 클릭·음량 조작은 화면 표시와 사용자의 명령 실행을 위해 기기 안에서 처리합니다. 포인터 이동, 클릭이나 키 입력을 행동 분석용 로그로 축적하지 않습니다.

3. 처리 목적
등록 영상의 바로가기 목록 표시, 자동 숨김 아이콘바 표시, 영상 실행, 재생 탭 재사용, 일시정지·이어재생·정지·반복, 슬롯별 음량 저장과 복원, 지원되는 광고 임시 음소거, 사용자 요청에 따른 설정 백업·복원을 위해 사용합니다.

4. 외부 전송 및 제3자 제공
확장 프로그램은 위 정보를 개발자 서버, 광고 서비스 또는 분석 서비스로 전송하지 않습니다. 사용자 데이터를 판매하거나 광고·신용도 판단·대출 목적으로 이용하지 않습니다. 원격 분석 도구나 외부 실행 코드도 포함하지 않습니다.
사용자가 등록한 영상 주소를 실행하면 Chrome이 해당 웹사이트에 직접 접속합니다. 해당 사이트는 자체 방침에 따라 네트워크 접속 정보, 로그인 상태 및 재생 정보를 처리할 수 있으며, 그 처리에는 해당 사이트의 개인정보처리방침이 적용됩니다.
사용자가 JSON 내보내기를 선택하면 설정 파일을 기기에 다운로드합니다. 내보낸 파일에는 등록 주소·이름·아이콘·음량 등이 포함되며, 사용자가 파일을 타인에게 공유하면 해당 정보도 함께 전달될 수 있습니다. 확장 프로그램이 이 파일을 자동으로 업로드하지 않습니다.

5. 처리하지 않는 정보
확장 프로그램은 계정 가입을 요구하지 않으며, 비밀번호·인증 쿠키·건강 정보·금융 및 결제 정보·이메일이나 채팅 내용·정밀 위치 정보를 수집하는 기능이 없습니다. 영상이나 소리 자체를 녹화·녹음하거나 전체 웹 방문 기록을 목록으로 저장하지 않습니다.

6. 보관 기간과 삭제
로컬 설정은 사용자가 변경·삭제하거나 확장 프로그램을 제거할 때까지 해당 Chrome 프로필에 유지됩니다. 설정에서 슬롯을 삭제하거나 전체 초기화 후 저장하면 목록을 변경하거나 기본값으로 되돌릴 수 있습니다. 현재 재생 제어 정보는 세션 동안 사용하며, 재생 대상 탭 종료 등 상태 변화에 따라 변경·삭제되고 브라우저 세션 종료 시 사라집니다.
JSON으로 내보낸 백업은 Chrome의 확장 저장소와 별도의 파일이므로, 사용자가 파일을 직접 삭제해야 합니다.

7. 권한
storage: 설정과 현재 재생 제어 상태를 저장·복원하기 위해 사용합니다.
scripting: 패키지에 포함된 코드로 허용된 웹페이지에 바로가기 바를 표시하고, 등록해 실행한 영상의 재생을 제어하기 위해 사용합니다.
선택적 HTTP·HTTPS 사이트 접근: 일반 웹페이지의 아이콘바 표시와 사용자가 등록한 영상 사이트의 재생 제어를 위해 사용합니다. 설정 저장 시 Chrome 권한 요청으로 허용 여부를 선택할 수 있으며, Chrome의 확장 프로그램 사이트 접근 설정에서 변경할 수 있습니다. 권한을 제한하면 일부 기능이 작동하지 않을 수 있습니다.

8. 방침 변경과 문의
기능이나 처리 방식이 변경되면 이 방침과 Chrome 웹 스토어의 데이터 사용 공개 내용을 함께 갱신합니다. 문의는 ‘내 영상 바로가기’의 Chrome 웹 스토어 등록 페이지에 표시된 개발자 연락처를 통해 보내 주세요.
